Predictive Loading

Predicts the next thing you will load from your own history and does the waiting early: DNS lookups for every app on your Mac, and the next page on each site in Chrome. Nothing leaves your device.

Install on macOS

brew install questboy23/tap/predictive-loading
predictive-loading enable
predictive-loading stats

predictive-loading uninstall restores your DNS settings exactly and deletes all data.

Install in Chrome

git clone https://github.com/Questboy23/predictive-loading
predictive-loading/install/setup.sh chrome

A guide window opens beside Chrome, points at each button, and can do the clicks for you (Extensions page, Developer mode, Load unpacked, pick the folder). Or by hand: download the extension zip from the latest release, unzip, open chrome://extensions, turn on Developer mode, and choose Load unpacked. Permission requested: storage only.

Measured results

Offline replay: the predictor's log-loss beat an order-1 Markov baseline on 6 of 6 traces. On recorded Chrome history it guessed the next domain correctly 31.5% of the time.

In the 50-site Chrome test below, each site had one training visit; the extension rarely passed its own threshold and showed no page-load gain. API calls through the Mac tool were 8.81 ms faster per call after the first round and slower on the first call (paired difference -9.96 ms).
